# AIとの進め方

Expo アプリを AI と作るときの進め方。構成・ライブラリ・設定（[フォルダ構成](./フォルダ構成.md)・[選定ライブラリ](./選定ライブラリ.md)・[開発環境と設定](./開発環境と設定.md)）とは別の関心事なので、分けて持つ。

この資料は任意。アプリが自分の進め方に合わせて、そのまま使うか、差し替えるか、外すかを選ぶ。

## 依存パッケージの追加

依存パッケージを追加するときは、**事前に提案して、承認を得てから入れる。** 提案には次の 4 つを含める。

* 目的
* 候補と採用理由
* ネイティブの依存か（再ビルドが要るか。[開発ビルドと Expo Go](./開発環境と設定.md#開発ビルドと-expo-go)）
* 保守の状況（最後のリリースなど）

入れ方は[依存パッケージ](./開発環境と設定.md#依存パッケージ)に従う。

## 完了の報告

完了を報告する前に、`lint`・`typecheck`・`test` をすべて通す（[スクリプト](./開発環境と設定.md#スクリプト)）。

## 公式ドキュメントの確認

Expo は破壊的変更が多い。ライブラリの API に触る前に、使用中の版の公式ドキュメントを確認する。記憶で書くと、古い API を使うことがある。
