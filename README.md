# keel-template-expo

Expo アプリの共通ベース。フォルダ構成・選定ライブラリ・開発環境・テスト方針を決めた上で、動くサンプルアプリを載せている。ここから新しいアプリを作る（手順は[アプリにする](./docs/アプリにする.md)）。

決めたことと、その理由は [docs/](./docs/) にある。資料の一覧と、AI（Claude）に作業を頼むときの入口は [CLAUDE.md](./CLAUDE.md)。使っているライブラリは[選定ライブラリ](./docs/選定ライブラリ.md#採用一覧)。

## 実行手順

必要なもの: Node 24。

```bash
nvm use                          # Node を .nvmrc の版（24）にする（nvm の場合）
npm install
cp .env.example .env.local       # 接続先の API を設定する（.env.local はコミットされない）
npm run web                      # http://localhost:8081 をブラウザで開く
```

* iOS / Android では、Expo Go ではなく**開発ビルド**で動かす。作り方は[開発環境と設定](./docs/開発環境と設定.md#開発ビルドの作り方)。
* サンプルは、公開のダミー API [DummyJSON](https://dummyjson.com) に接続する（認証も投稿も同じ接続先）。ログインは、ユーザー名 `emilys`、パスワード `emilyspass`。投稿の作成は保存されないので、作成しても一覧には出ない。
* 実物の DummyJSON に繋いだ Web では、Cookie が送られないため、ログインしてもリロードでログイン画面に戻る（[認証](./docs/認証.md#web-の-cookie-が送られる条件)）。ネイティブは、再起動してもログインのまま。
* コマンド（lint、型、テスト、E2E、API クライアントの生成）の一覧は、[開発環境と設定](./docs/開発環境と設定.md#スクリプト)。

## サンプルアプリ

ログインと、投稿の一覧・詳細・作成、設定の画面。構成の使い方の見本になる。

| 画面                 | 見本になっていること                                                                                                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ログイン             | 新しい feature（`auth`）、React Hook Form + Zod、ログイン後の処理の hook、`Stack.Protected` で未ログインを入れない、起動時の復元（済むまで描かない）                                            |
| ホーム（投稿の一覧） | 生成された hook でのデータ取得、クエリパラメータ（キーワード）での絞り込み、4 状態（Loading・Error・Empty・Data）、`FlatList`、`expo-image` のアバター、最大幅と中央寄せ（`sm:`・`md:`・`lg:`） |
| 投稿の詳細           | 動的ルート（route で `id` を読み、props で画面に渡す）、データに依存するタイトル                                                                                                                |
| 投稿の作成           | React Hook Form + Zod、更新後のキャッシュの無効化、入力中に離れるときの確認（`Dialog`）、ログイン中のユーザーを投稿者にする                                                                     |
| 設定                 | Jotai の atom（AsyncStorage に保存）、複数の feature で使うので `src/hooks/` に置く、ログイン中のユーザーの表示とログアウト                                                                     |
